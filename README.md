# GO development HW1

## Calc

### Запуск программы из файла:

```bash
go run main.go "[your expression]"
```

### Создание исполняемого файла:

```bash
go build -o ./bin/
```

### Запуск исполнямого файла:

```bash
./bin/calc "[your expression]"
```

### Запуск тестов:

```bash
go test -v ./calc/
```
